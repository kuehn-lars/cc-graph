# Changelog

Versions follow semver. Each release names the Claude Code versions it was tested on.

## Unreleased

F06 import edges are in the graph state, and the terminal graph (F09) now draws them. On other surfaces a ghost is a `⋯` row in the list, and its row names its importer. F06's manual check waits for F09's (ticket 07).

- F09 layout: when a write adds or removes nodes or edges, one pass runs after the hook has returned and stores every node's position in `layout`. Files of a folder start around the folder's seed point, offset by a hash of their path; a pass is deterministic, takes at most 200 iterations and moves no node more than 2 units; positions of evicted nodes are dropped, and `/clear` empties `layout` (F09-AC1..AC3, AC12, R3, R4, F03-R7, NFR-P4).
- F09 queue: slow work is enqueued and drained by one coalesced `$.clock.after` callback, one job at a time, a failing job dropped (D5). At most one layout pass waits at a time; F07's `git` jobs will use the same queue.
- F09 graph: nodes are drawn at their stored position (a node with none, at its folder's seed point) and each import edge as a line of half-block pixels between node cells, the glyphs on top. A cell with only its bottom pixel lit is `▄` (F09-R1 amended: `▀` would paint the unlit top in the terminal's foreground) (F09-R1, R5, R9, NFR-P3).
- F09 rings, memory and legend: a changed node's cell takes its ring as background (amber edited, green created, grey external, red blind); memory files are `■` cells along the bottom-left in path order, and nodes keep off them. A legend line under the graph names the glyphs, the `■` and the rings on screen and no other, cut and closed by `…` when wider than the pane; it takes a row from the raster. The list says what the graph draws: a file's row ends with `imports n`, a ghost's says `imported by login.ts` and `+n` for further importers (F09-AC8, AC10, R1, R5, R8, R10, NFR-A3).
- F09 labels: the selected node, changed nodes and the 5 largest by tokens show their file name to the right of their cell. A label that would cover a node or memory cell, another label, or run off the raster is dropped, so no glyph is erased (F09-R6 amended with AC6); a character a `Raster` would refuse (wide, or outside the BMP) is drawn as `?` (F09-AC6, AC11, R6, NFR-A3).
- F09 pulse: a node Claude touches while the graph is shown gets a ring of highlighted cells for one second, by two `$.ui.blit` calls (ring on, 1000 ms later off) that add no render pass. The ring is drawn after the layout pass and its redraw have run; the ring takes only blank and edge cells, so a glyph, label or change ring is never covered. A render in between ends the pulse early, a newer pulse keeps an older one from clearing it, and a denied blit is ignored (F09-AC9, R7).
- F09 card: the terminal graph is a dark card of braille dots with half-block rounded corners and a sparse grid. Each file is a shape sized by its tokens (filled disc, half disc, dotted circle, outline, `!`, cross), ringed in its change's colour and, when selected, in white; import edges are dotted lines from ring to ring; the graph is fitted to the card and a node is clamped so its rings stay inside. Memory files leave the raster and the one-cell glyphs, half-block edges and cell backgrounds are gone; labels sit two columns right of the outermost ring and the pulse is one white ring until ticket 13 (F09-AC13, AC14, AC15, AC27, R12, R14, R15, R16, R22).
- F09 flow layout: importers settle at least 10 units above what they import and import edges pull to 14 units; a new node starts 8 units below its most recently touched placed importer (or above what it imports, or at its folder's seed point) and moves freely in its first pass, while nodes with an earlier position keep the 2-unit cap. Linked pairs skip the pairwise repulsion, so the spring alone sets an edge's length (F09-AC25, AC26, R4, R13).
- F09 boxes: the braille card is gone. Each file is a rounded box on the terminal's own background holding its list glyph, name and change word, solid in context and dashed otherwise, with a size bar along its bottom side; a ghost is a tag without a box. Boxes are fitted to the pane per axis and moved off each other, and a node with no room becomes a tag. Import edges are box-drawing lines at right angles that turn where they cross the fewest boxes and join the boxes' sides. The focus has its border and edges in Claude's orange, and the pulse flashes its border white, shimmer, orange. Colours are Claude Code's own theme keys: the lines around the graph follow the person's theme, and the raster paints the dark theme's values. The header leads with `✻`, the now line with `⏺`, and the legend uses the list's glyphs and says "changes" (F09-AC17, AC21, AC22, AC27..AC37, R11, R18, R21, R23..R29).
- F09 folders: each folder is a frame titled with its path (`src/auth/`, `./` at the root) around its files, so two `index.ts` can be told apart. Folders stack in layers, a folder that imports from another above it, with each layer's frames centred under their importers; inside a folder an importer's line sits above what it imports. Folders without imports either way fill free room at the top right. When the pane is short, the tallest folder's boxes become one-row tags first, and only then a folder is left out: one without a change before one with, the one touched longest ago first, never the focus's. Edges always run top down, enter where they cross the fewest boxes and titles, go round a folder in the way, and cross a frame at `┼` (F09-AC33, AC38..AC40, R26, R30).
- F09 colours: an edit reads `+2 −1` with the added lines green and the removed lines red, as a diff colours them; a deleted file's box, border and word are red and its name dimmed; a focused tag has its name in Claude's orange. The legend ends its first line with `━ size`, saying what the bar under a box is (tokens in context, against the largest file), and names `deleted` (F09-AC29, AC41..AC43, R24, R27..R29).
- F07 shell changes (pulled into v0.2): after each `Bash` call the mod compares `git status` with its baseline, off the hook's path, and marks what the command did: `created` (untracked, added, renamed to), `deleted` (`D`, renamed from, or an untracked file gone) or `changed unseen`, each with "created by", "deleted by" or "changed by" and the command. A file Claude changed with `Write` or `Edit` is never blamed on a command. Outside a repository the footer says "Shell changes need git" (F07-AC2, AC12..AC15, R1, R5, R6, R8).
- F02 an `ls` after a search in the same command no longer adds its folder headers (`src/auth:`) as search nodes (F02-AC18, R2).
- Faster terminal frames: the raster is one typed array encoded as is, and edge routing sums its costs without building paths (NFR-P3).

- F06 import edges: a successful text `Read`, `Write` or `Edit` links the file to the files it imports, parsed from `file.content`, `content` and `newString`. The node, its edges and its ghosts land in one write of `graph`, under the same eviction cap (F06-AC1, AC8, R1, I5, I9). The mod reads no file to find them (F06-AC4, R8).
- F06 import edges: an imported file with no node becomes a `ghost`, held by nobody (`mainLoop: false`, no agents). An existing node keeps its state (F06-R7).
- F06 import edges: one edge per pair of files, none from a file to itself, and none removed; a second read of `login.ts` adds nothing (F06-AC10, R10).
- F06 TypeScript, with JavaScript (`.ts`, `.tsx`, `.mts`, `.cts`, `.js`, `.jsx`, `.mjs`, `.cjs`): `import … from`, `import 'x'`, `export … from`, `require('x')` and `import('x')`. Comments and strings that look like imports are skipped. Only relative specifiers link: packages, `node:` built-ins and aliases such as `@/lib/x` add nothing (F06-AC2, AC9, R2, R5).
- F06 TypeScript resolution: the path as written when it has a known extension, then each extension of the importer's own family, then the other family, then `/index`. A TypeScript file's `./util.js` tries `util.ts`, then `util.tsx`, before the path as written, and `.jsx`, `.mjs` and `.cjs` try `.tsx`, `.mts` and `.cts`. `.`, `..` and `x/` name a folder's index. An import whose extension belongs to no language (`./styles.css`, `./user.service`) links only to a node that already exists, so it makes no ghost such as `styles.css.ts`. A target outside the working directory keeps its absolute path (I4), so imports from a sibling package link too (F06-AC7, R3).
- F06 Python (`.py`): `from .x import y`, `from . import x`, `from ..x import y`, `import a.b` and `from a.b import c`. Each extra dot goes one package up, and `x.py` is tried before `x/__init__.py`. An absolute module links only to a node that already exists (F06-AC3, R2, R4).
- F06 picking a target: a candidate that is already a node, and not a ghost, wins, and the edge is not `guessed`. Otherwise the first candidate wins, the edge is `guessed`, and its target becomes a ghost. A ghost does not confirm anything, so a second importer of a guessed file still guesses (F06-AC6, R6; F06-Q3 open on clearing `guessed` later).
- F06 limits: text over 200,000 characters adds nothing, whichever of the three tools it came from, and so does a file whose extension belongs to no language, such as an import shown in `docs/usage.md` (F06-AC5, AC11, R9, R11). AC5's 300,000-character `Read` and the R9 and self-import cases are derived from recorded results, because a `Read` over 256 KB errors.
- F06 setting: `importEdges` ("Show file imports", on by default, F14-R1) in `/config`. When it is off, a `Read`, `Edit` or `Write` parses no imports, so a read of `login.ts` adds `login.ts` alone, with no edge and no ghost (F06-AC12, R12). Edges already in the graph stay until `/clear` (F06-Q2).
- F06 recording: `fixtures/sessions/imports.ts` comes from a real `claude -p` run that reads `src/auth/password.js`, `src/auth/login.ts`, `src/a.ts`, `app/models.py`, `app/views.py` and `docs/usage.md`. It is written by `scripts/record-imports-session.mjs` with the `imports-probe` mod, and `fixtures/sessions/README.md` explains how to record it again.
- Specs: F06 Approved. Each language is one entry (TypeScript with JavaScript, and Python), and R6 now says a ghost is a guess, not a confirmation. F14 gains the `importEdges` row, and ROADMAP v0.2 gains F14 (`importEdges`) and its exit gate.
